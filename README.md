# 🔐 Password Generator

A simple and interactive password generator built using HTML, CSS, and JavaScript. It allows users to create strong and customizable passwords based on selected criteria.

---

## 📌 Overview

This project generates secure passwords with user-defined options such as length, uppercase letters, lowercase letters, numbers, and symbols. It also provides a visual strength indicator for the generated password.

---

## 🚀 Features

- Adjustable password length using a slider  
- Option to include:
  - Uppercase letters  
  - Lowercase letters  
  - Numbers  
  - Symbols  
- Password strength indicator  
- Copy to clipboard functionality  
- Clean and modern UI  

---

## 🛠️ Tech Stack

- **HTML5** — Structure  
- **CSS3** — Styling and layout  
- **JavaScript** — Logic and interactivity
